Scenario 1: CNCC Restarts on restart-date Annotation (Primary Bug Fix)

Objective: Verify that cloud-network-config-controller restarts when hypershift.openshift.io/restart-date is set on the HostedCluster.

Maps to: JIRA reproduction steps and acceptance criteria

Cluster: brcox-sm-dev-hc (Azure, 4.22.0-rc.3) — KUBECONFIG=/Users/brcox/aws_dev_kubeconfig

Overall Scenario 1: PENDING

Commands

HC_NAMESPACE=clusters-brcox-sm-dev-hc

# Step 1-2: Record before state
oc get pods -n $HC_NAMESPACE -l app=cloud-network-config-controller -o custom-columns=NAME:.metadata.name,CREATED:.metadata.creationTimestamp

# Step 3: Set annotation
oc annotate hostedcluster -n clusters brcox-sm-dev-hc hypershift.openshift.io/restart-date=$(date --iso-8601=seconds) --overwrite

# Step 4-6: Verify after (wait up to 5 min)
oc get pods -n $HC_NAMESPACE -l app=cloud-network-config-controller -o custom-columns=NAME:.metadata.name,CREATED:.metadata.creationTimestamp
