Scenario 1: CNCC Restarts on restart-date Annotation (Primary Bug Fix)

Objective: Verify that cloud-network-config-controller restarts when hypershift.openshift.io/restart-date is set on the HostedCluster.

Maps to: JIRA reproduction steps and acceptance criteria

Cluster: brcox-88531-hc on Azure dev mgmt cluster — HCP namespace: clusters-brcox-88531-hc

Overall Scenario 1: PASS
StepCheckResultEvidence
1 CNCC pod running in HCP namespace PASS cloud-network-config-controller-859cdd9f9b-cdxls Running
2 Record pod name and creation timestamp (before) PASS Pod 859cdd9f9b-cdxls created 2026-06-16T15:51:21Z
3 Set restart-date annotation on HostedCluster PASS Set to 2026-06-16T17:40:15Z; annotation propagated to HCP
