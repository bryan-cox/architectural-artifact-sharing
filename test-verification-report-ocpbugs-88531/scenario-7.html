Scenario 7: Non-Cloud Platform Unaffected (Negative Test)

Objective: Verify the fix does not break non-cloud platforms (e.g., KubeVirt, None) where CNCC is not deployed.

Note: This scenario requires a non-cloud-platform HostedCluster (KubeVirt or None). If unavailable, this test can be deferred to CI or marked N/A.

Commands

# Step 1: Check platform
oc get hostedcluster -n clusters <non-cloud-hc> -o jsonpath='{.spec.platform.type}'

# Step 2: Set annotation
oc annotate hostedcluster -n clusters <non-cloud-hc> hypershift.openshift.io/restart-date=$(date --iso-8601=seconds) --overwrite

# Step 3: Verify no CNCC
oc get pods -n clusters-<non-cloud-hc> -l app=cloud-network-config-controller

# Step 4: Check other operands
for deploy in multus-admission-controller network-node-identity ovnkube-control-plane; do
  echo "--- $deploy ---"
  oc get pods -n clusters-<non-cloud-hc> -l app=$deploy -o custom-columns=NAME:.metadata.name,CREATED:.metadata.creationTimestamp
done

# Step 5: Check CNO logs
oc logs -n clusters-<non-cloud-hc> deployment/cluster-network-operator -c cluster-network-operator --tail=100 | grep -i "restart-date"
