Scenario 4: Idempotent Behavior — Same restart-date Does Not Re-Trigger

Objective: Verify that repeated reconciles with the same annotation value do not cause pod flapping.

Cluster: brcox-88531-hc on Azure dev mgmt cluster — HCP namespace: clusters-brcox-88531-hc

Note: The annotation was already set to 2026-06-16T17:40:15Z during Scenario 1. This test re-applies the same value and verifies no new rollout.
