Scenario 4: Private DNS Zone Naming

Objective: Verify the private DNS zone uses the correct naming format {name}.{baseDomain} instead of the old {name}-azurecluster.{baseDomain}.

Overall Scenario 4: PASS — Both checks verified.
StepCheckResultEvidence
1 New naming format zone exists: {name}.{baseDomain} PASS Zone brcox-100054-hc.hcp-sm-azure.azure.devcluster.openshift.com confirmed via az network private-dns zone list. See Appendix G and raw evidence below.
2 HostedCluster privateZoneID uses new naming PASS Full resource ID: /subscriptions/237432b9-.../privateDnsZones/brcox-100054-hc.hcp-sm-azure.azure.devcluster.openshift.com. See Appendix B and raw evidence below.
