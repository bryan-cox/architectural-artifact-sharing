Scenario 3: Platform Create Commands — No Regression

ObjectiveVerify hcp create cluster subcommands for AWS, Azure, and KubeVirt work without regression after adding ctrl.SetLogger()
Maps toNo regression in existing CLI functionality
Evidence ScopeLocal: CLI flag parsing and help output. E2E: CI jobs for full create-verify-destroy lifecycle.
Result: PASS — All three platform create commands pass local CLI validation. Full end-to-end lifecycle confirmed by CI jobs.
Testing Scope: Local testing only covers CLI flag parsing — the logger call is in main() before any cobra command runs, so if flag parsing works, the logger didn't break cobra. Full create-verify-destroy paths require real cloud infrastructure and are covered by CI e2e jobs. This is the appropriate level of evidence for a change that adds one line (ctrl.SetLogger(newLogger())) before the cobra command tree executes.
